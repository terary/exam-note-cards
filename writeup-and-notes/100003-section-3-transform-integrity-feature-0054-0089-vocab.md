`HDFS` - Hadoop file system. It is temporary but super fast for caching intermediate results (less compute time)

`YARN` - Yet Another Resource Negotiator
`MapReduce` - __Framework to create Application that processes vasts amount of data in parallel__

`TF-IDF` - TF-IDF (Term Frequency-Inverse Document Frequency) is a crucial numerical statistic in machine learning and NLP that measures a word's relevance within a document relative to a collection of documents (corpus). It boosts words frequent in a specific document but rare across the corpus, effectively filtering out common stop words like "the" or "and".
