### Notes
#### One Hot Encoding
One-hot encoding isa data preprocessing technique in machine learning that converts categorical data into a numerical, binary format (0s and 1s). It creates new binary columns (dummy variables) for each unique category, marking 1 for the presence of a value and 0 otherwise. This prevents algorithms from assuming a false order or ranking between categories. Key Aspects of One-Hot Encoding Purpose: It transforms non-numerical, nominal data (eg, "Red", "Green", "Blue") into a format that models can understand without imposing unintended numerical relationships.How it Works: If a feature has\(N\)unique categories, one-hot encoding creates\(N\)new binary columns. For instance, a "Color" column with "Red", "Blue" would become two columns: is_redand is_blue. A red item is\([1,0]\)and a blue item is\([0,1]\).Benefits: It eliminates the issue where algorithms treat numerical labels (eg,\(1,2,3\)) as having ordinal relationships (like\(3>1\)).Drawbacks: It can lead to high-dimensional, sparse data (curse of dimensionality) if a column has too many unique values. It can also create multicollinearity, where variables are highly correlated.Alternative to Avoid Dummy Variable Trap: To prevent high correlation, one column is often dropped, reducing\(N\)categories to\(N-1\)columns. Example Original Data: ["Apple", "Banana", "Orange"]One-Hot Encoded:Apple:[1, 0, 0]Banana:[0, 1, 0]Orange:[0, 0, 1]
